# Conjuntos de datos — corte DOM-INM-2026-09-01

**Estado:** `SIN_CONJUNTOS_ADMITIDOS`

Este directorio es el destino canónico de los conjuntos de datos, cohortes o manifiestos de acceso que hayan superado evaluación documental, clínica, ética, jurídica y técnica. Su contenido apoya la contrastación empírica del dominio; no constituye por sí mismo conocimiento clínico, causalidad ni consecuencias de ignorancia.

## Regla de incorporación

Un conjunto solo puede entrar en `main` después de quedar individualizado por:

- identificador, responsable, repositorio y versión o fecha exacta;
- finalidad original, población, criterios de inclusión y exclusión;
- unidad observacional, tamaño de cohorte, variables y desenlaces;
- temporalidad, nivel de agregación, datos faltantes y transformaciones;
- diccionario o esquema de datos y procedencia;
- licencia, condiciones de acceso y autorización de redistribución;
- elegibilidad para tratamiento mediante IA;
- anonimización y riesgo de reidentificación;
- jurisdicción, limitaciones, residual y cobertura inmunológica;
- procedimiento reproducible de obtención y huella criptográfica cuando proceda;
- revisión adversarial y decisión humana expresa.

## Datos no redistribuibles o de acceso controlado

No se copiarán al repositorio. Se conservarán el identificador de acceso, la versión, la consulta o procedimiento de extracción autorizado, el diccionario, las restricciones y la huella del resultado obtenido cuando sea lícito.

## Separación obligatoria

- La asociación estadística no se registrará como causalidad clínica.
- La cobertura de una cohorte no se presentará como cobertura del dominio.
- Los datos agregados no sustituirán sucesos singulares cuando estos sean clínicamente determinantes.
- No se incorporarán datos personales ni material con riesgo de reidentificación no resuelto.
- Los candidatos permanecen en la rama `dominio-inmunologia` hasta su admisión.
