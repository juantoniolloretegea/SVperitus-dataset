# OP-IMM-001 / Q0 v0

## Identidad

Universo de información predecisional pertinente antes de iniciar tratamiento inmunosupresor en adultos. Contiene un subconjunto formalizado de veintisiete parámetros; no equivale al cribado infeccioso completo previo a la inmunosupresión ni autoriza una decisión asistencial.

## Regla de crecimiento

Las revisiones de este universo se incorporarán mediante una versión nueva cuando cambie una fuente, regla, configuración, finalidad prevista, población, jurisdicción, programa ejecutable o contrato de salida. No se modificará silenciosamente el significado de una ejecución anterior.
