## Distinciones obligatorias

1. **Dominio no es agente.** El dominio deberá definirse de forma completa respecto de su perímetro y versión. Un agente posterior podrá recorrer todo el dominio, un subdominio o una cobertura expresamente delimitada.
2. **Perfil de dominio no es perfil fuente.** Puede reutilizarse una disciplina común de identidad, versionado, trazabilidad y composición, pero no se presume igualdad semántica con los perfiles lingüísticos español e inglés.
3. **Composición no implica superagente.** La combinación de dominios, perfiles o agentes exige relación semántica previa, tipado visible, resolución explícita de colisiones, procedencia por objeto y codominio declarado.
4. **Inmunología es precedente metodológico y falsador, no plantilla ontológica.** No se importarán vocabulario clínico, cardinalidades, salidas ni supuestos propios de `OP-IMM-001`.
5. **El Lenguaje SV no decide la verdad de ciberseguridad.** Puede exigir identidad, representabilidad, determinismo, integridad y trazabilidad, y registrar necesidades de extensión; no puede recortar el dominio para acomodarlo a la IR vigente.
6. **El dominio tampoco legisla el núcleo.** Toda necesidad que no sea representable se entregará como requisito y testigo de pérdida; no se convertirá por conveniencia en una primitiva universal.
7. **Los modelos de IA no son autoridad normativa.** Se tratarán como artefactos o componentes versionados, identificados y reproducibles. Quedan prohibidas las dependencias flotantes como `latest` y las invocaciones en vivo dentro de una cadena normativa reproducible.
